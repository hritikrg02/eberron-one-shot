This document contains a description of how this wiki works. On the left-hand side, you will see a a title, a search bar, one or more folders, and then a list of documents underneath. Clicking the title will take you back to the [[001 Administrative/Welcome\|Welcome]] page and the search box works as you’d expect. Underneath that are the folders. There will likely be no more than a few, since folders are not the main way this wiki meant to be navigated. As such, you can see that most articles are simply listed in alphabetical order beneath the folders.

Navigation on this wiki is a bit different than most file-based workflows. Instead of folders which places documents into a linear hierarchy, most documents are contained in the root directory and navigation works in one of two ways:
- If there is specific document or phrase you are looking for, you can scroll the document list or use the search box.
- You can navigate using wikilinks.

A **wikilink** is a special kind of link that links two documents together. This allows for navigation through the links themselves. In many cases, any time a document references some “thing”, it will link to the document that contains information on that thing. Two types of links exist: [[001 Administrative/Welcome\|Lavender Links]], which take you pages that already exist, and [[Pink Links\|Pink Links]], which are pages that do not exist yet but may in the future.

On the right-hand side, you will see two main items: the graph view, and the outline. The **graph view** visually represents what wikilinks exist between whatever document you are viewing and all other documents. The purple dot in the middle represents the current documents, and the grey dots represent other existing documents that are linked. A grey line between dots indicates that two documents are connected via a wikilink, meaning that one, the other, or both contain a wikilink to the associated document. Clicking on the expand icon will blow-up the current graph view, and clicking on the globe icon will show the **global graph** – showing the network between all documents that currently exist in the wiki.

The **outline** is simply a list of headers that exist within the current document, and can be used to navigate individual documents by jumping the page to where that header is located. This is especially useful for longer documents with longer headers.
